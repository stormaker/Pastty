# 安装与使用 Pastty 开发预览

Pastty 是 MIT 开源的本地文字/图片剪贴板历史工具。当前安装包使用 ad-hoc 开发签名，**未经 Apple 公证**，适合愿意参与反馈的测试用户。普通用户无需安装 Rust、Homebrew 或 Xcode。

当前提供 Apple Silicon（M 系列）版本。最低系统目标为 macOS 14；本机实际运行环境为 macOS 27，macOS 15 上已完成远程构建与打包。macOS 14 实机、Intel 与跨机器安装验证仍待完成。

## 安装

1. 从本项目的 GitHub Release 页面取得标有 `dev` 的 DMG，阅读该次发布的测试范围和已知限制。
2. 打开 DMG，将 **Pastty.app** 拖到 **Applications**，再从 Applications 中打开。
3. 测试期间可保留“显示菜单栏图标”，方便随时打开设置或退出。

如果当前版本尚未公开发布，先使用开发者提供的本地安装包；CI artifact 只是构建产物，不等于正式版本。

## macOS 提示无法验证开发者时

未公证版本可能被 macOS 阻止打开。确认文件来自本项目并且你愿意测试后，可以按 Apple 提供的单个应用操作流程：先尝试打开一次，再进入 **系统设置 → 隐私与安全性**，找到 Pastty 对应的提示，选择 **仍要打开**，按系统要求确认。

如果提示文件可能损害电脑、已被篡改，或下载文件的校验和与发布值不一致，应停止安装并反馈；不要把它当成普通的未公证提示处理。

官方步骤：[在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。这个操作只针对你选择的应用，不需要更改全局的应用来源策略。

## 复制与粘贴

- 在其他应用复制文字或图片，Pastty 会在后台记录。
- `⌘V` 仍按系统原有方式粘贴当前内容。
- 点击菜单栏图标或按默认快捷键 **`⌥V`**，打开 **Pastty** 历史菜单。
- 用鼠标或 `↑` / `↓` 选择条目；点击或按 `Enter` 后回到原窗口粘贴。
- 按 `Esc` 或点击菜单外关闭，不改变当前剪贴板。

选中旧历史后，它成为系统当前剪贴板内容，接下来按 `⌘V` 会继续粘贴它。图片需要目标应用本身接受图片粘贴。

## 自动粘贴权限

自动发送粘贴按键需要辅助功能权限。进入 **系统设置 → 隐私与安全性 → 辅助功能**，添加 Applications 中的 **Pastty.app** 并启用。未开启时，历史选择仍会把内容复制到剪贴板；回到目标应用手动按 `⌘V` 即可。

系统如果另外询问是否允许访问剪贴板，请按你的选择处理。开启辅助功能不等于系统替你认可了安装包，也不等于公证已经完成。

开发预览更新后，系统可能要求重新确认权限；请确认列表中的应用仍是 Applications 中的当前 Pastty。官方说明：[允许无障碍 App 访问你的 Mac](https://support.apple.com/zh-cn/guide/mac-help/mh43185/27/mac/27)。

## 三项设置

菜单底部点 **设置…**：

| 设置 | 行为 |
|---|---|
| 显示菜单栏图标 | 关闭后快捷键仍可使用；从 Applications 再次打开 Pastty 可返回设置 |
| 历史快捷键 | 点快捷键按钮，按新的组合键；冲突时保留原快捷键；`⌘V` 保留给系统 |
| 登录后自动启动 | 由 macOS 登录项机制管理；需要系统允许时按提示操作 |

关闭设置窗口只关闭窗口。要停止记录，请在 Pastty 菜单底部点 **退出**。

## 数据与范围

历史和配置保存在本机 `~/Library/Application Support/Pastty`；不做云同步，也不把剪贴板正文写入日志。

默认最多500项、30天、256 MiB有效内容；文字单项1 MiB、图片单项16 MiB。超限项目不存历史，但不影响系统正常复制粘贴。400ms轮询可能漏过很快连续复制之间被覆盖的中间内容。文件引用、富文本、搜索、OCR和置顶不在极简版本范围内。

删除应用通常会保留历史。需要完全移除时，先关闭登录后自动启动并退出，将应用移到废纸篓，再自行决定是否删除上面的数据目录。

## 测试反馈

反馈时请注明系统版本、芯片、Pastty版本、触发步骤，以及是否已启用辅助功能；若涉及文字/图片，请使用不含隐私的示例。具体已经验证和仍待验证的内容见[首版验收](首版验收.md)。
