# Pastty 0.1.0 开发预览验收

日期：2026-10-24。环境：Apple M4 / 24 GB，macOS 27.0.1，Rust/Cargo 1.94.0，Release arm64构建。此记录区分实现、验证和公开发行，不能用本机检查替代他人机器验收。

## 本轮交付

- Rust历史/配置核心与轻量Objective-C/AppKit桥；单进程、无WebView。
- 文字/PNG/TIFF历史、按需读取原数据、SHA-256去重、500项/30天/256 MiB限额、私有文件权限与崩溃恢复。
- 以Maccy菜单为参考的紧凑原生历史：点击图标直接打开、单行文字、小图片预览、自适应高度、鼠标/方向键选择、Enter回贴、Esc取消；窗口与标题统一为Pastty。
- 三项设置：图标显示、历史快捷键、登录后自启动。重新打开现有实例可进入设置。
- 应用图标依据用户实际提供的剪贴板SVG设计。可编辑SVG、1024px PNG、完整ICNS与单色菜单图标均已落盘，原SVG保留且哈希复核一致。
- 标准.app、本地开发DMG、依赖许可证收集与macOS CI配置。

本机隔离smoke可复现：

```sh
PASTTY_DATA_DIR="$(mktemp -d /tmp/pastty-smoke.XXXXXX)" \
PASTTY_SMOKE_TEST=1 dist/Pastty.app/Contents/MacOS/pastty
```

smoke仅使用固定示例和隔离目录；不读写系统剪贴板、不注册自启动。需要目视菜单可额外设置`PASTTY_SMOKE_HOLD_SECONDS=60 PASTTY_SMOKE_VIEW=history`。目录由执行者保留用于检查。

## 资源观察及边界

最终Release正常监听模式在隔离数据目录观察约25秒，没有主动操作界面；期间检测到一次约12.4 MiB图片复制。`vmmap -summary`记录当前physical footprint **29.9M**、峰值**42.5M**；`ps`的RSS约64–78 MiB，5次CPU快照为0.0%、0.0%、0.0%、6.5%、0.1%。两种内存口径不同，不能只报较小值。图片处理期间存在短时峰值。

这是短时功能/资源观察，尚不足以确认长期空闲CPU预算、长期无增长、复杂历史下内存目标或8小时稳定性。原始本机指标与研究原件存于Git忽略的`research/verification/`。
