# 本地构建与验收

本项目使用Rust核心和AppKit原生界面。普通安装用户不需要开发工具。以下命令面向构建者，需macOS、Apple Command Line Tools、Rust工具链和构建期间使用的Python 3。项目最低系统目标为macOS 14；正式兼容声明仍需对应机器验证。

## 开发构建

在项目根目录运行：

```bash
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked --all-targets
scripts/build-app.sh
scripts/make-dmg.sh
```

`build-app.sh`读取Cargo版本，编译当前架构Release二进制并生成`dist/Pastty.app`。没有Developer ID身份时使用ad-hoc签名，并添加开发预览标记。构建不安装、不启动应用，也不注册登录项。设置`CARGO`/`RUSTC`可选择工具链可执行文件。

可显式指定目标：`scripts/build-app.sh aarch64-apple-darwin`或`x86_64-apple-darwin`；目标标准库须事先安装。脚本只打包指定架构，不自动声称Intel已测试。`BUNDLE_ID`可覆盖开发标识，正式签名发布前需固定；默认`com.stormaker.pastty`。`BUILD_NUMBER`默认1，发布时递增。

`make-dmg.sh`从已验证app生成`Pastty-版本-架构-dev.dmg`，包含可拖拽应用、Applications快捷方式及MIT许可证。脚本验证DMG校验和并只读挂载，检查应用及快捷方式；旁边生成`.dmg.sha256`。同名DMG存在时退出，先移走旧产物再重建。

签名前自动运行`collect-licenses.py`，以`cargo metadata --locked --offline --filter-platform`读取指定目标的完整依赖图，沿普通/构建依赖收集缓存包中的LICENSE、COPYING、NOTICE等原文；dev-only依赖排除，构建工具/过程宏许可作为保守超集保留。原文按SHA-256去重，但保留每个crate名称、版本、SPDX声明与原文归属。SQLite C代码的public-domain声明单独从其实际源码头部收集。输出位于应用Resources/DEPENDENCY-LICENSES.txt，包含未解决数量，不写本机构建路径。该步骤不联网、不执行依赖代码；它是通知收集，不替代第三方许可人工审查。

## 验证含义

`scripts/verify-release.sh`检查包结构、plist、Mach-O架构、二进制部署目标和代码签名。开发验证通过，不表示已公证、可在他人Mac无提示运行，亦不表示自动粘贴/自启动/内存测试通过。

`scripts/verify-release.sh --public`还要求Developer ID Application、hardened runtime、已装订公证票据与Gatekeeper通过；开发预览标记存在会拒绝。当前没有签名身份或公证凭据时，它应失败，而不是把ad-hoc构建伪装成正式分发。

开发构建可带明确列出的未知许可警告；设置签名身份的构建使用`collect-licenses.py --strict`，存在未解决项则在签名前停止。`--public`验证也要求依赖通知存在且未解决数为0。

正式构建需将证书放在Keychain，设置`SIGNING_IDENTITY`。应用公证与staple完成后，设置预先存入Keychain的`NOTARY_PROFILE`，运行`scripts/make-dmg.sh --public`，它会对最终DMG签名、公证、staple并验证。脚本不收集/保存明文密码。实际凭据准备和发布流程见[发布与开源](发布与开源.md)。

## CI与待执行验证

`.github/workflows/ci.yml`使用`macos-15`Apple Silicon runner，执行格式、lint、测试、app与开发DMG打包，并保留14天CI artifact。actions以完整提交SHA固定；checkout v6.0.2、upload-artifact v6.0.0均为Node 24版本。CI不创建tag、不发布GitHub Release，不请求签名秘密。定义workflow并不代表远程CI已通过。

开发环境需要实测以下流程并保留结果：

- 文字复制、图片复制、去重、历史淘汰和重启后历史读取。
- 默认/自定义热键、方向键/鼠标选择、Enter回贴、Esc和点击外取消。
- 在真实编辑器、浏览器和微信验证回贴及焦点；没有辅助功能权限时降级为手动粘贴。
- 隐藏菜单图标后重新打开设置，登录启动开启/关闭与重启后实际状态。
- Release构建常驻内存、图片瞬时峰值和反复开关窗口后的回落。指标口径见技术选型文档。
- 另一台Mac在下载隔离属性下的拖拽安装、首次运行、权限、自启动与卸载。

以上是验收清单，不是已完成证据。真实执行结果由本轮测试记录另行登记。

官方依据：[GitHub macOS runner规格](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)、[checkout v6.0.2](https://github.com/actions/checkout/releases/tag/v6.0.2)、[upload-artifact v6.0.0](https://github.com/actions/upload-artifact/releases/tag/v6.0.0)。

## 图标

`assets/clipboard-source.svg`保留用户提供的剪贴板轮廓；`assets/Pastty.svg`为可编辑的应用图标。预生成PNG与ICNS已提交，普通应用构建无需图形渲染工具。需要重新生成图标时，安装librsvg提供的`rsvg-convert`后运行`scripts/build-icon.sh`；它使用macOS的sips/iconutil生成完整iconset，菜单栏资源保持单色template以支持深浅色。
