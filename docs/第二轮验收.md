采样峰值physical footprint为38,618,048字节（约36.83 MiB），起止增加6,225,944字节（约5.94 MiB）。峰值是每100轮等有限时点采样的最大值，不能当成连续监测的绝对峰值。每轮缓存/行引用释放检查通过，但起止增长仍需后续长时与重复区间观察，不能据此宣称“没有内存泄漏”。

## 测试模式的入口保护

所有smoke运行都要求`PASTTY_SMOKE_TEST=1`、显式绝对路径、已存在的空目录。Rust在准备目录、创建锁或打开Store之前只读验证；生产历史目录及其子目录、符号链接、非空或缺失目录均拒绝。

新增真实二进制用例验证：漏设隔离路径先报错、已有历史字节和目录权限不变、非法循环参数不会创建目标目录。压力次数限制1–10000，脚本默认1000。验证不改正常运行模式的热键与菜单行为。

可复现命令：

```sh
cargo test --locked --all-targets
cargo test --locked --test storage_stress -- --ignored --nocapture
scripts/build-app.sh
scripts/stress-native.sh 1000
scripts/make-dmg.sh
```

原始原生日志及本机汇总位于Git忽略的`research/verification/round-02/`；脚本也会在其新建临时目录中保留`run.log`。
