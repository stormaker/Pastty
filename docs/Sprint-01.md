# Sprint 01 — 可运行的原生首版

状态：首版实现、本机开发预览与DMG结构验证完成；跨应用/长时/正式分发验收待完成，详见[首版验收](首版验收.md)。基线提交：3f5ef11。目标：从文字/图片复制到历史选择及回贴，完成三项设置，构建可安装的本地开发预览。

## 工作拆分

1. Rust存储：SQLite元数据、按内容哈希的数据文件、去重、500项/30天/256MiB淘汰、配置。
2. 原生界面：AppKit历史列表、文字与缩略图、Option+V/方向键/鼠标/Enter/Esc。
3. 系统集成：有限轮询、敏感类型忽略、回写去重、目标焦点与修饰键释放、辅助功能失败回退、单实例。
4. 设置：菜单栏图标、快捷键录制、SMAppService登录项实际状态。
5. 构建交付：Release应用、开发签名DMG、CI检查、真实界面与资源验证。

存储与原生界面通过C ABI连接；Rust为历史/配置核心，Objective-C只实现AppKit和系统API桥接。相比研究阶段提出的objc2直接绑定，此选择减少桥接调试成本，保持原生单进程与无WebView设计。无需Swift或JS运行时。

## 关键约束与验证

| 约束 | 验证 |
|---|---|
| 历史有界，去重不重复计费，淘汰删除图片文件 | 临时目录存储测试，数量/字节/到期边界 |
| 文字与图片可完整回读，预览不影响原文 | Unicode和图片字节往返测试 |
| 读取过程中剪贴板变化不保存混合内容 | native changeCount前后比较；真实流程检查 |
| 自身写回不重复捕获 | 自定义pasteboard标记与同步changeCount检查 |
| Esc不改变剪贴板；选中仅发送一次粘贴 | 原生事件路径审查与本机验证 |
| 无辅助功能时仍能选中复制 | 授权拒绝路径本机验证 |
| 隐藏图标可重开设置，重复启动不产生第二个监听 | 单实例锁与reopen通知测试 |
| 快捷键失败保留旧注册和配置 | 热键注册/持久化错误路径审查 |
| 自启动状态来自系统，关闭设置不退出进程 | SMAppService状态读取和UI检查 |
